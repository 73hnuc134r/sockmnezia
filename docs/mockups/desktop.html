Settings · Connection mode
Off
Apps use the proxy only if you set them up (SOCKS or HTTP, with the password).
System proxy
Windows / GNOME / KDE use an HTTP port on 127.0.0.1. The system can't store a password, so this port has none while the mode is on.
Any program on this computer, from any user account, can use it while it is on.
PAC
Only addresses your routing sends through the proxy; the rest go direct.
TUN
All traffic of this computer, also from apps without proxy settings. Needs administrator rights once (Windows service / Linux helper). DNS and local network settings as on Android.
If the chain breaks, traffic is blocked, not sent directly.
Previous system settings are saved and restored on stop, quit, and after a crash.

The tray switches chains and servers (recent ones first) and the system proxy without opening the window. The system-proxy behaviour shown is plan option A (decided, D30); TUN is §3a.
